# Logos

The oxide-lattice mark (3×3 FeO crystal face) and the OpenFeO wordmark, outlined (no font needed). Each file has fixed colours — pick by ground; `<img>` cannot recolour them.

- `openfeo-wordmark-on-dark.svg` — Fe dots and "FeO" in dark-theme `oxide` #f0773f, O dots and "Open" in dark-theme `ink` #e7ebee. Use on `ground`/`surface` in the dark theme.
- `openfeo-wordmark-on-light.svg` — Fe dots and "FeO" in light-theme `oxide` #b13f0d, O dots and "Open" in light-theme `ink` #14181c. Use on light grounds.
- `openfeo-mark.svg` — the lattice alone for dark grounds (oxide + ink #e7ebee), 20px and up.
- `openfeo-mark-light.svg` — the lattice alone for light grounds (oxide #b13f0d + ink #14181c), 20px and up.
- `openfeo-favicon.svg` — single ink #d9612a, O dots enlarged so the pattern survives at 16px; reads on both light and dark browser tabs.

Pair dark/light files with the `ofo-on-dark` / `ofo-on-light` classes. Clear space: one dot pitch on every side. Minimum: mark 20px, wordmark 20px tall.
