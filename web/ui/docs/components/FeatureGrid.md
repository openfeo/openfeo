# FeatureGrid

A grid of what OpenFeO does, for the website: `ofo-features` containing `ofo-feature` cells divided by 1px `line` gutters.

**Provide** per feature: a 28px stroke icon (`__glyph`, oxide), a 2–4 word `__title`, one sentence of `__text`, and an optional mono `__meta` fact (a number or a command, never a superlative).

Cells auto-fit at 220px minimum; use 3 or 4 features per row, 8 at most overall.

**Don't** use emoji, coloured left borders, or invent benchmark numbers — `__meta` must be measurable.
