# EmptyState

What a list or table shows before it has anything in it: `ofo-empty` with the lattice mark (`__art`, Fe dots in oxide, O dots in ink-muted), a `__title`, one line of `__text` and usually the primary create action.

**Provide** a title saying what's missing ("No port forwards yet"), a sentence with a concrete example, and the action that fixes it.

**Don't** use it for errors (Banner) or for "no results" after filtering — show "No rules match `ssh`" inline in the table instead.
