# Menu

A short list of actions on one row or object, opened from a ghost `…` button: `ofo-menu` with `ofo-menu__item` buttons, `ofo-menu__sep` dividers and an optional `<kbd>` shortcut.

**Provide** 2–7 verb-first items, the destructive one last after a separator with `ofo-menu__item--danger`, and full keyboard support (arrows, Esc returns focus to the trigger).

**Don't** hide the page's primary action in a menu, or nest menus.
