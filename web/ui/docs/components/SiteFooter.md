# SiteFooter

The website's closing block: `ofo-sitefoot` with a brand column (wordmark + one-sentence description) and up to three link columns, then a `__legal` row in mono.

**Provide** the wordmark (both theme files), a single sentence, 3–4 links per column, and the legal row: licence, any disclaimers, current version.

**Don't** add newsletter forms, social icon rows or "Made with ♥".
