# DownloadCard

One downloadable build per card: `ofo-downloads` grid of `ofo-dl` with an `__arch` label, `__title`, a `__meta` list (file, size, checksum) and a button at the bottom.

**Provide** the architecture, version, exact filename, size and SHA-256 (truncate in the middle on screen; full value on hover and on the release page). The build most people want gets `ofo-dl--primary` and the primary button; others use the secondary button. Include a Source card.

**Don't** label builds "Recommended" or "Latest" — the version number says it.
