# Segmented

Two to five mutually exclusive views of the same data — chart ranges, IPv4/IPv6 — as a row of buttons in `ofo-seg` with `aria-pressed` on the chosen one.

**Provide** short labels (1–2 words or units like `24h`) and a `role="group"` with an `aria-label`.

**Do** use it to filter or re-scale what is already on screen. **Don't** use it for settings that need Apply (use Choice radios) or to switch whole pages (use Tabs).
