# Brand

The OpenFeO mark and wordmark, and how to place them.

**What it is.** A 3×3 face of iron oxide's rock-salt crystal: big iron (Fe) dots in `oxide` at the corners and centre, small oxygen (O) dots in `ink` between them. The wordmark sets **Open** in `ink` and **FeO** in `oxide`, in Instrument Sans at weight 620, converted to outlines. In motion the flat face opens into the full 3-D lattice (see MarkMotion).

**Files** (uploads in the Logos group; fixed colours, so pick the file for the ground):

- `openfeo-wordmark-on-dark.svg` — on dark grounds (`ground`/`surface` in the dark theme).
- `openfeo-wordmark-on-light.svg` — on light grounds.
- `openfeo-mark.svg` / `openfeo-mark-light.svg` — the lattice alone for dark / light grounds, 20px and up.
- `openfeo-favicon.svg` — one-colour version with enlarged O dots for 16px (browser tabs, the panel's favicon), readable on light and dark tabs.

**Provide** both theme files and let CSS pick: `class="ofo-on-dark"` on the dark version, `class="ofo-on-light"` on the light one.

**Do**
- Clear space: one dot pitch (a third of the mark) on every side.
- Minimum size: mark 20px (favicon file below that), wordmark 20px tall.
- On `oxide-deep`, draw the O dots in `on-oxide-deep` (as MarkMotion does) or place the wordmark on a `ground` plate.

**Don't**
- Swap which dots are big, recolour the Fe dots, rotate the grid 45°, add more rows, or set "OpenFeO" in live text beside the mark as a substitute for the wordmark.
- Write it "OpenFEO", "Open FeO" or "openfeo" in prose. The name is **OpenFeO**; lowercase `openfeo` only for the binary, package and domain.
