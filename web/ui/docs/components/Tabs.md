# Tabs

Sub-pages of one object — an interface's Overview / Addressing / Failover probes — in a `role="tablist"` of `role="tab"` buttons; the selected one gets `aria-selected="true"` and an oxide underline.

**Provide** 2–6 nouns, an optional count in `ofo-tabs__count`, and the matching `role="tabpanel"` below. Arrow keys move between tabs.

**Don't** use tabs to filter a table (use Segmented) or for a step-by-step flow.
