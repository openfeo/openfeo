# Toggle

An on/off switch for a setting that takes effect on Apply: a real `<input type="checkbox">` inside `ofo-toggle`, followed by `ofo-toggle__track` and the label text.

**Provide** the label naming the feature, not the action ("UPnP", not "Enable UPnP").

**Do** use it for feature flags in a form. **Don't** use it to trigger an immediate action (use a Button) or for choices of more than two (use a select).
