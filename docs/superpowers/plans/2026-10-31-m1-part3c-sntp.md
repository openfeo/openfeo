# M1 Part 3c: SNTP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The router keeps its own clock right from SNTP servers (configured, defaulting to `pool.ntp.org`, plus the ones the WAN lease names), never earlier than the build, publishes `time.synced` as a fact, and answers SNTP on every LAN, which the DHCP leases now point at; the last item of SPEC §12 M1.

**Architecture:** A pure crate `openfeo-proto-sntp` holds the 48-byte codec, the client state machine (`Client::handle(Input, Now) -> Vec<Output>`: polling, failover, the four-timestamp offset, RFC 4330's sanity checks, the build-time floor), the steering decision (`discipline`: the first sync steps, offsets under half a second slew, larger ones step) and the LAN-side responder. `openfeo-net::sntp` moves the packets (one UDP socket towards the servers, a UDP 123 listener bound to each LAN bridge) and `openfeo-net::clock` applies decisions through `adjtimex` behind a `Clock` trait, so the sandbox suite runs the real driver against a recording clock and a GPS/PPS source can feed the same discipline later. Names resolve through our own forwarder, which gains a loopback listener. PID 1 raises a clock that starts before the build to the build timestamp. The router task `crates/openfeo/src/time.rs` follows the World (configured servers, the WAN's learned ones, the LAN bridges), publishes `World.time`, and logs the console contract. The lab gets a Python SNTP server whose offset the scenarios dial and busybox `ntpd` as the LAN-side reference client.

**Tech Stack:** Rust stable 2024, tokio (UDP, mpsc), nix 0.30 (`time` feature for `clock_settime`, `SO_BINDTODEVICE`), `libc::adjtimex` inside `openfeo-net`'s one unsafe module (ADR-0013), prost/pbjson, insta, cargo-fuzz; harness: python3 (the lab's SNTP server), busybox `ntpd` (the LAN-side client), dnsmasq (already the lab's resolver), QEMU `-rtc base=`.

**Spec:** `SPEC.md` §7.10 (Time), §7.6 (LAN DHCP options: NTP), §8.2 (`[system] ntp_servers`), §6.1 (PID 1 duties), §6.3 and §13 (sans-IO cores, pure crates), §11 (harness), §12 (M1 row). Brainstorm outcome (2026-10-31): the router is the LAN's time server by default (DHCP option 42 = the router); the clock steering is written to take samples from any source so a GPS receiver with a PPS line slots in later; crates were considered (`ntp-proto` of ntpd-rs pulls rustls, tokio, serde and a crypto backend; `sntpc` and `rsntp` are std clients) and the house pattern chosen.

## Review Focus

1. A server whose transmit time is before the build timestamp (a server stuck in 2013, a factory default of 1970) must be refused and the clock left alone; a reasonable person expects a wrong server to be reported, never obeyed. Test `a_transmit_time_before_the_floor_is_refused` (Task 2).
2. A reply whose originate timestamp is not the one we sent, or that comes from an address we did not ask, must be ignored (RFC 4330 §5: the only defence against an off-path spoof). Test `replies_that_do_not_match_what_we_sent_are_ignored` (Task 2).

```rust
// discipline.rs
/// The kernel's single-shot slew bound, and ours: under it we slew, from it we step.
pub const STEP_THRESHOLD_NS: i64 = 500_000_000;
/// At the first sync a clock this close is slewed rather than stepped (an RTC box is usually here).
pub const FIRST_STEP_THRESHOLD_NS: i64 = 128_000_000;
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Decision { Step(i64), Slew(i64), Hold }
pub fn decide(offset_ns: i64, synced_before: bool) -> Decision;   // Hold only for an offset of 0

// client.rs
pub const POLL_UNSYNCED_MS: u64 = 16_000;
pub const POLL_SYNCED_MS: u64 = 1_024_000;
pub const REPLY_TIMEOUT_MS: u64 = 2_000;
/// Consecutive failures that mark a server down, and how long it stays so.
pub const MAX_FAILURES: u8 = 3;
pub const SERVER_HOLD_MS: u64 = 1_024_000;
/// Rounds without a valid sample after which a synced clock is declared unsynced.
pub const LOST_SYNC_ROUNDS: u8 = 4;
/// RFC 5905 MAXDISP: a sample whose root distance reaches it is unusable.
pub const MAX_ROOT_DISTANCE_NS: i64 = 16_000_000_000;
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Config { pub servers: Vec<Ipv4Addr>, pub floor_unix_secs: u64 }
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Input { Poll, Reply { server: Ipv4Addr, bytes: Vec<u8> }, Configure(Config) }
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Output { Send { server: Ipv4Addr, bytes: Vec<u8> }, Step(i64), Slew(i64), Event(Event) }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Reject { Unsynchronised, KissOfDeath([u8; 4]), Mismatch, Format, RootDistance }
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Event {
    Configured { servers: usize },
    NoServers,
    Step { server: Ipv4Addr, offset_ns: i64, stratum: u8 },
    Synced { server: Ipv4Addr, offset_ns: i64, delay_ns: i64, stratum: u8 },
    Slewed { server: Ipv4Addr, offset_ns: i64 },
    Refused { server: Ipv4Addr, transmit_unix_secs: i64, floor_unix_secs: u64 },
    Rejected { server: Ipv4Addr, reason: Reject },
    ServerDown(Ipv4Addr),
    ServerUnusable { server: Ipv4Addr, code: [u8; 4] },
    LostSync { rounds: u8 },
}
/// What the clock knows about itself; the responder and `World.time` read it.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub struct SyncState {
    pub synced: bool, pub source: Option<Ipv4Addr>, pub stratum: u8,
    pub offset_ns: i64, pub delay_ns: i64, pub root_delay_ns: i64, pub root_dispersion_ns: i64,
    pub reference: NtpTimestamp, pub last_sync_unix_secs: Option<i64>,
}
pub struct Client { /* config, servers' state (failures, hold_until, unusable), pending {server, transmit, sent_at}, round index, sync state, consecutive empty rounds, rng */ }
impl Client {
    pub fn new(config: Config, seed: u64) -> Client;
    pub fn handle(&mut self, input: Input, now: Now) -> Vec<Output>;
    pub fn next_poll(&self) -> Option<u64>;      // mono_ms of the next Poll the driver should feed
    pub fn state(&self) -> &SyncState;
    pub fn config(&self) -> &Config;
}
```

Pipeline. `Poll` at `now`: if a request is pending and `now.mono_ms >= sent_at + REPLY_TIMEOUT_MS`, the server takes a failure (`MAX_FAILURES` consecutive → `ServerDown`, held until `now + SERVER_HOLD_MS`) and the round moves to the next usable server; with no pending request, pick the next server not held or unusable (round robin over the list; when every server is held, the earliest hold is cleared), build a version 4 mode 3 request whose transmit timestamp is `now.unix_ns` with its low 32 fraction bits randomised from the seed (RFC 4330 §3 recommends it), remember it, emit `Send`. A round is one request to each usable server in turn; a round in which no server yields a valid sample counts as empty; `LOST_SYNC_ROUNDS` empty rounds while synced emit `LostSync` and clear `synced`. `next_poll` is `sent_at + REPLY_TIMEOUT_MS` while a request is pending, else the end of the current interval (`POLL_UNSYNCED_MS` unsynced, `POLL_SYNCED_MS` synced) measured from the last round's start, or `Some(0)` (poll now) right after `new` and `Configure`. `Reply`: decode (`Format` on error), `Mismatch` unless the server is the pending one and `originate == transmit we sent`, `Unsynchronised` for LI 3 or stratum ≥ 16 or a zero transmit, `KissOfDeath(code)` for stratum 0 (`DENY` and `RSTR` mark the server unusable for the rest of the run with `ServerUnusable`; `RATE` doubles that server's hold), `RootDistance` when `root_delay / 2 + root_dispersion >= MAX_ROOT_DISTANCE_NS`; then the transmit time (in Unix seconds with the floor as pivot) below `floor_unix_secs` → `Refused`, counted as a failure; otherwise offset `((T2 - T1) + (T3 - T4)) / 2` and delay `(T4 - T1) - (T3 - T2)` with `T1` our transmit, `T4 = now.unix_ns`; `discipline::decide(offset, synced)` → `Step` + `Event::Step` and `Event::Synced`, or `Slew` + `Event::Slewed` (and `Event::Synced` when not synced before), or `Hold`; the state updates (`synced`, `source`, `stratum`, offsets, `root_*` from the server, `reference = T3`, `last_sync_unix_secs`), failures reset, the round ends (one good sample per round; the other servers wait for the next). `Configure`: replaces servers (keeping each surviving server's failure state), drops the pending request if its server is gone, emits `Configured` and, with an empty list, `NoServers`; `next_poll` becomes `Some(0)`.
